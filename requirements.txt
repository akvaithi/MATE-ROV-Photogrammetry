# Reconstruction is a pluggable, auto-selected backend — no bundled engine:
#   • macOS   → RealityKit / Object Capture via a compiled Swift helper
#               (needs Xcode Command Line Tools: `xcode-select --install`).
#   • Windows → RealityScan (Epic, free for students / sub-$1M teams) preferred;
#               install from realityscan.com. Meshroom is a fallback but REQUIRES
#               an NVIDIA CUDA GPU.
#   • Linux   → Meshroom (alicevision.org), NVIDIA CUDA GPU required.
#
# The in-app 3D preview shows a native thumbnail where available (macOS Quick
# Look) and delegates interactive rotation to the OS 3D viewer (Windows "3D
# Viewer" / Quick Look / xdg-open) — so no heavy 3D library (pyvista/VTK) is
# bundled and it works fully offline.
